# 🏍️ Motocross Shop

Welcome to **Motocross Shop**, a web development project inspired by the passion, excitement, and community of motocross. Established as a project in 2025, it aims to provide an online destination for motocross riders looking for quality gear, accessories, and essential motorcycle parts.

## 🏁 About the Project

Motocross Shop is designed to serve riders of all experience levels, from beginners discovering the sport to experienced riders preparing for their next race. The envisioned product range includes helmets, gloves, goggles, knee guards, protective equipment, and motorcycle parts.

Our goal is to create a user-friendly platform where riders can explore motocross products and eventually enjoy a complete online shopping experience, with an emphasis on safety, comfort, quality, and style.

## 💻 Technologies

The project is built using:

- **PHP** — server-side logic and user authentication.
- **MySQL** — database management and user information storage.
- **HTML5** — page structure and content.
- **CSS3** — styling and responsive layouts.
- **Bootstrap 4** — interface components and layout support.

## 🔐 Current Features

- User registration with name, surname, email, and password.
- Login system with email and password validation.
- Password hashing using PHP's `password_hash()` and verification with `password_verify()`.
- Session-based authentication.
- Database integration using PDO and prepared statements.
- Custom login and registration pages with a motocross-inspired design.

## 🚀 Future Improvements

The project is intended to evolve into a more complete motocross e-commerce platform, with potential features such as:

- Product catalogues and category filtering.
- Product details, prices, and availability.
- Shopping cart and checkout functionality.
- User profiles and account management.
- Order history and order tracking.
- Improved security, validation, and deployment configuration.

## 🎯 Mission

Motocross Shop aims to bring riders closer to the equipment they need to ride with confidence. Inspired by the motocross community, the project focuses on combining functionality, usability, and a distinctive visual identity while providing a foundation for future development.

**Motocross Shop — Ride with passion. Ride with confidence.** 🏁
